括号里的是力扣题目的标号

```java
// 数组常用方法
Arrays.sort(arr); // 默认升序
    // 如果arr是自定义类型，可以用三种方法lambda，reverserOrder接口，或者comparator比较器修改为降序
    // 如果arr是int，double，char等基本类型，sort()无法返回，需要转变为Integer，Float等包装类型
    Arrays.sort(arr,(a,b)->b-a);
    Arrays.sort(arr,Collections.reverseOrder());
    Arrays.sort(arr,new Comparator<Integer>(){
        // compare返回的是正数时交换a，b的位置
        @Override
        public int compare(Integer a, Integer b){
            return b-a;
        }
    })

Arrays.asList(arr);
// 该方法返回的是一个不可变的list，需要重新初始化
new ArrayList<>(Arrays.asList(arr));
```

## 1. 移除元素（27）

1. 双指针

    题目要求空间为O(1)，但是可以理解为快指针数组和慢指针数组。快指针寻找非val的值，慢指针作为新数组的指引。


## 2.有序数组的平方（977）

1. 双指针

    初始数组是有序的，可以左右两个指针向中间比较。


## 3. 长度最小的子数组（209）

1. 滑动窗口

    当sum<target，右指针继续往前寻找；当sum>=target，左指针往前，减少sum的值，从而达到滑动效果。
